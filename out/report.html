Latency is the gap between the server's timestamp and local receipt. OEE here is computed from the source timestamp, so this latency does not bias the result — it only tells you how live a dashboard built on this feed would be.
OEE = Availability x Performance x Quality. Availability is run time over planned production time; performance is ideal cycle time times total count over run time; quality is good count over total count. Planned stops are supplied from the shift plan, not inferred from the machine data, because a controller reports the same IDLE state for a planned break and for waiting on material. Counters are summed as positive deltas so a counter reset does not corrupt the total.
